Design Section 1 — Visual System Upgrade

Three upgraded templates showing the new design language. This applies across all 12 + 1 new template.

Global changes applied to every template

Slide number as design element

The "01", "05" etc. move from a small counter pill to a prominent top-left accent — emerald monospaced number + category label + accent line. Sets editorial tone immediately.

Footer redesigned

Bottom strip becomes the brand footer from the reference: TheStatsAndStacks logo + wordmark on left, "FOLLOW @THESTATSANDSTACKS / FOR VISUAL BREAKDOWNS ON MONEY, MARKETS & STRATEGY →" on right.

Background texture

Hairline grid swapped for a subtle dot-grid (radial-gradient dots). Richer depth, less rigid, matches the reference images exactly.

Prop interface breaks (intentional)

CashflowSlide gets real dollar values + per-category arrays. AI agent prompts updated alongside every template change so the AI always sends the right payload.
